One line of software error copy, at most 200 characters, that tells the user the brutal truth about what went wrong — and makes them laugh on the way.

The program writes a single honest error message to `/output/entry.txt`:

> We lost your file. The backup job has failed silently for 11 months, and its alerts went to an inbox nobody reads.
